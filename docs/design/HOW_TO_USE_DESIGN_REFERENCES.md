# Use with Codex in Android Studio

1. Download and extract the Pageheld design kit at the **root** of your local Pageheld repository. Preserve this `docs/design` folder structure.
2. Check that both files exist:
   - `docs/design/references/pageheld-ui-overview.png`
   - `docs/design/references/notebook-paper-reference.png`
3. In Codex, send: "Open and inspect `docs/design/PAGEHELD_CODEX_VISUAL_BRIEF.md` and both image references under `docs/design/references/`. Implement the native Android app in this Pageheld repo, prioritizing the notebook editor and visual fidelity. Follow the brief exactly and build/test as you proceed."
4. If Codex's image-viewing support isn't available, attach the PNG images directly in Codex chat if supported, or use an image-capable environment. Never ask Codex to guess the images from filenames.
5. Compare screenshots from the running emulator to the references; refine differences. The showcase is a design target, not a pixel-perfect replacement for functional Android UI.
6. Review Git changes before merging or pushing.
