# Library comparison

The disposable emulator began with ten review books. Testing the phone edition added its default Memospine notebook to the same database. For the final captures the tablet's management controls moved that notebook to the second shelf page. The first page shows nine independent covers and the second shows the remaining two. The empty-library image came from a fresh install before loading review data. The New Book image shows the separate creation dialog.

The reference is 1672 × 941. The actual capture is 1672 × 941 with a 30 px status bar and a 40 px navigation area. The comparison uses equal-width application viewports. This preserves the difference in their aspect ratios. No image-similarity score is used.

First capture: neutral luminance multiplication made the materials too dark, especially leather. The header took too much vertical space and the shelf arrows lacked the round control surround. The corrections center luminance on each selected color, reduce the tablet header height, retain both page arrows and use a separate lower strip for indicators. A further correction leaves air above books on successive shelves and reduces the visible size of individual texture threads.

The three shelf spans and slot centerlines follow the reference. The shelf face still has flatter grain and less depth. The source stickers have visible die-cut edges. The reference's pressed flowers, clasp and lace are absent from Vol. 01. These differences remain open for visual acceptance. See [artwork requirements](../../ARTWORK_REQUIREMENTS.md).
