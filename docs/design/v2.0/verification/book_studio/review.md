# Book Studio comparison

The centered “Days in Jeju” title is a saved book title from the review fixture. The material selector and all lettering use live Compose controls. The photo-placement capture uses a local Android SDK emulator environment image imported through the system picker. The artwork stays selectable after import.

The comparison crops the illustrated device bezel and status bar from the Studio reference and excludes Android system bars from the emulator screenshot. It uses equal application widths. Content aspect ratios are preserved.

The first capture revealed incorrectly dark textiles, material images centered inside excessively wide swatches, an overly small preview and a wood desktop. Corrections increased the preview height, made each swatch square, changed the workspace to woven cloth, and gave ribbon and border choices physical previews. A device regression test covers the ribbon draw call, front/back editing, undo/redo, save, reopen and cancellation.

Three real materials occupy the selector. Three more material sources are requested. The live cover still lacks the illustrated botanical corner relief and extended bookmark of the reference. The front/back and undo strip occupies more horizontal space. Separate captures show the text controls, sticker catalog, imported photo and back cover.
