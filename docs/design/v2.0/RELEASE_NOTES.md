# Memospine. 2.0

Draft for Min's Makes. Publication is pending release acceptance.

Pageheld is becoming Memospine. Your existing notebook, pages, drafts, photographs, locations and chapters move into one book during the update. Your entries keep their original titles.

## Tablet edition

Open Library to find your books on three shelves. Swipe sideways or use the arrows to see the next nine books. **New Book** asks for a title, material and color. Tap a book to open it. Long-press its cover, or use **Manage books**, to rename, decorate, move, duplicate its design or delete it. Duplicating a design leaves the original journal entries in their book.

In Book Studio, choose **Front** or **Back**. Select a material and color, add lettering, import a photograph, or add stickers, frames and tape. Tap a layer to select it. Use the layer controls to adjust its placement, scale, rotation, opacity or stacking order. **Done** saves the design.

Today and Moments show the selected book. Its title appears above the daily journal or map. Enter a different book from Library to change the destination. Writing tools and page navigation are at the top. **Stickers** opens page decoration controls for the current sheet.

## Phone edition

The phone edition opens Today and uses the original notebook navigation. It reads and writes the legacy book. A full-library backup taken on the phone also includes books from a restored tablet library.

## Install, update and back up

For a production update, download the appropriate APK from the official Min's Makes release and choose **Update**. Keep your existing installation. Android requires the original signing identity. Both editions share the same application ID and replace each other when installed on one device.

Before updating, use the Profile screen to export your encrypted notebook and store the file and passphrase separately. After installation, check your familiar chapters, pages and photographs. Use Profile → Import to merge an encrypted backup. Existing entry IDs are kept. New entries retain their book ownership. The full-library format is intended for Memospine 2.0. Keep a separate Pageheld backup if you still need to read it with an older version. The existing 256 MiB uncompressed archive limit applies.
