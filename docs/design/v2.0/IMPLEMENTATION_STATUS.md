## Data and navigation decisions

The phone explicitly uses the legacy book. A tablet opens Library. Today and Moments are scoped to the selected book. The stable page ID owns locations and diary layout. Each page decoration belongs to a sheet ID inside that entry. The library stores book order, front and back designs and last-read entry separately from global appearance settings.
